# The Set Helsinki Enterprise 3.5 — Payroll PRO

Adds selectable 21–20 payroll periods, TES hour/pay breakdown, Sunday/holiday 100% premium, configurable evening/night/aatto/overtime supplements, S/VL/VV visibility, 3-week overtime summary, hour-bank delta/balance, payroll adjustments support, labour-cost KPI cards and print-friendly payroll.

Run `supabase/migrations/011_payroll_pro.sql` once after upgrading from 3.4.

Important: supplement values are intentionally configurable and default to 0. Confirm current TES/company rates before payroll use.
