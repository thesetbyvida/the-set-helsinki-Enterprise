# The Set Helsinki Enterprise 2.0 — Phase 2 Restaurants

Entrega acumulativa: incluye Fase 1 + Fase 2.

Incluye autenticación, idiomas, roles y gestión completa de restaurantes: crear, editar, activar, desactivar, eliminar, dirección, teléfono, email, color, logo y horarios por día.

## Supabase
Ejecuta en orden:
- supabase/migrations/001_foundation.sql
- supabase/migrations/002_restaurants.sql

Si ya ejecutaste Fase 1, ejecuta solo 002_restaurants.sql.

## Vercel
Framework: Vite
Build: npm run build
Output: dist

## GitHub
Descomprime el ZIP y reemplaza el contenido del repositorio de Fase 1 por esta entrega acumulativa.
