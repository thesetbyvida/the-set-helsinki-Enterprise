# Production Certification — 5.6

The 5.6 release is the final QA/certification release for The Set Helsinki Enterprise.

1. Deploy to the existing Vercel project.
2. Open Settings → System status and run the automated checks.
3. Confirm the automated result is `PRODUCTION READY`.
4. Complete every applicable item in `PRODUCTION-CHECKLIST.md` with real restaurant data.
5. Do one full payroll flow from rota entry through a closed payroll period and historical report.
6. Keep the last known-good Vercel deployment available for rollback until the manual checklist is complete.
